# codex-xhs-autogain

「Codex 自动获客」复刻项目：小红书 AI 内容获客工具拆解与复刻（辅助创作定位）。

## 这是什么
视频号 35.7s 引流视频中展示的「Codex 自动获客」工具复刻版：
- **采集**：关键词搜索 → 详情/作者粉丝补全 → 评分（低粉爆款 4 维权重）
- **一键克隆**：拉取爆款笔记 + 下载图片 → 生成可编辑的新稿（标题/正文/标签）
- **发布**：本地 Web 界面发布（拟人化护栏：随机延迟/冷却/熔断/时段限制）
- **风控纪律**：自动互动=平台 2026-03 公告点名对象，仅谨慎档+测试号；账号买卖不做（法律风险）
