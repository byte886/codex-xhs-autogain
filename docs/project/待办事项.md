## 三、已知边界（如实记录，避免重复踩坑）

1. **发布永远手动**（红线）：自动化不代发；发布相关自动化只到"草稿/校验/引导"为止。
2. **生产无 CDP 承诺**：跨窗口自动监控扫码并导入 Cookie 不承诺；主路径=引导用户扫码后回 APP 点「立即读取 Chrome 登录态」。
3. **采集数据用完即失效**：每次搜索清库；长期留存仅发布/存草稿 + **客户线索（clients 表，O1 运营资产）**。
4. **平台限流未解除**：任何真实链路测试前先低频单次探测；触发 captcha 即停并清理。
