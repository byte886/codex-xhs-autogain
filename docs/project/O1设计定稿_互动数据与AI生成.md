## 2. 调研结论（谷歌 + MCP 双源互证）

### 谷歌侧（已精读）
- **zhekehub 小红书 AI 图文创作工具 V2.52**：同行链接提取→AI 标题总结/改写→AI 正文创作/改写→文生图/图去重/微调/重绘→素材保存→手机预览扫码发布。**三栏工作台**（左参考原笔记/中创作/右手机预览）。标题正文**分开处理、结果可编辑**。
- **LobeHub「小红书内容自动生成发布系统」(yyh211-xiaohongshu)**：**LLM Key 门控的完整范例**——Web 界面配置 `LLM API Key / OpenAI Base URL / Default Model`，存本地 JSON config，`GET /api/config` 隐藏敏感，配「测试连接」。生成流程：检索→写作(标题≤20字/正文800-1200字/emoji)→格式适配(提取5话题标签)→发布。集成 Jina/Tavily/小红书 MCP。
- **QClaw（腾讯云）**：输入爆款链接→分析爆款因素→生成类似笔记（标题结构相似内容不同、配图风格一致素材新、标签覆盖关键词）。
- 其他：autocrew（npm，AI 内容运营流水线含 AI 味审查）、RepurposeAI（本地 Ollama 模式）、优采云/百度文库（SaaS 批量文案）。

## 3. 设计定稿

### 3.1 AI 文稿生成模块（可选，Key 门控）——用户硬约束：未配 Key 不可用

**配置**（参考 LobeHub）：
- `data/llm_config.json`（key 加密/不返回前端）：`llm_api_key / openai_base_url / default_model`
- 前端「AI 设置」面板：三项输入 + 「测试连接」按钮 + 保存
- `GET /api/llm_config`（隐藏 key）/ `POST /api/llm_config` / `POST /api/llm_test`
- **未配置 → 前端 AI 按钮灰态+提示「前往 AI 设置配置模型」；后端 AI 接口返回 400 明确拒绝**

**生成能力**（挂在现有「克隆」功能内，作为可选增强，参考 zhekehub 分开处理）：
| 动作 | 说明 |
|---|---|
| AI 改写标题 | 总结/改写两动作，≤20字，保留原笔记爆款方向 |
| AI 创作/改写正文 | 按行业/赛道语义重写，结果可编辑 |
| AI 提取话题标签 | 5 个左右精准标签（小红书风格） |
| AI 生成私信话术 | 基于意向用户信息个性化（{昵称}替换模板为免费项，AI 个性化话术为门控项） |

生成结果全部进现有编辑区，编辑后再走现有发布（**发布永远手动**，红线不变）。

### 3.2 采集客户 + 意向分级（O1 核心，视频形态）

- 入口：笔记卡片「采集客户」按钮（视频同款：悬停卡片→采集）
- 采集范围：该笔记评论区用户（昵称/地区/回复时间/互动类型/原评论）
- **意向分级**（评分引擎扩展，初版规则）：
  - 高意向：留联系方式 / 主动询问价格/购买
  - 上意向：开口提问（问效果/问方法）
  - 中意向：表态互动（"我也想减"、"求方法"类）
  - 低意向：纯水评论/无自我信息
- 落库：`data/xhs_notes.db` 新增客户线索表（含来源笔记、采集时间）

### 3.3 数据聚合视图（P4 客户库升级）

- 聚合维度：总线索数（如 720h 窗口）、意向分布（高/上/中/低）、属地分布、近 7 天产出时间线、留联系方式统计
- 客户明细列表：昵称/地区/意向标签/来源视频/联系状态，支持导出线索 CSV
