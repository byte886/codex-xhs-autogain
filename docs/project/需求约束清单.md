## 五、讨论过程中被纠正/澄清的认知（重要，避免重犯）

| # | 认知 | 澄清 |
|---|---|---|
| 1 | "视频是完整课" | ❌ 视频只是推广/宣传/引流钩子，不是完整课程 |
| 2 | "复刻成自己用" vs "做成产品卖给同行"是一件事 | ❌ 两阶段：先自己做 MVP 跑通验证，再决定产品化（乔川/大周/袁欣均"先给自己搭、跑通身边人才来买"） |
| 3 | "克隆"是核心价值 | ⚠️ AI 亦仁：采集=爬虫、改写他人内容=擦边，建议"辅助创作"正向定位 |
| 4 | 调研方法可能只有一种 | ❌ 超级标/大航海/项目库有多个入口（activitylist/activitysearch/activitymanualsearch/projectlibsearch/searchprojectcases 等），多通道尝试判断 |
| 5 | 工具只解决内容生产 | ⚠️ 完整销售工作流=内容→发布→引流→成交，工具只覆盖前 4 步中的内容生产部分 |
| 6 | 用订阅模型做不了自动化 | ❌ Codex CLI 订阅可非交互调用（codex exec），豆包订阅不含 API token 但方舟 API 可按量付费 |

## 六、用户长期偏好（跨任务，来自 profile + 本次）

- 纯文字/表格化/普通 MD/PDF 交付；社交文案严禁 AI 化生硬表述
- 技术栈限定 TypeScript/Go/Rust/Python（排除 Java/Clojure）
- 消费观务实（高性价比优先）；偏好省力工具
- 自主推进默认"继续/不用问我"，但关键节点设人工闸口
- 涉及飞书知识库归档先询问
