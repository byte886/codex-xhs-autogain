## 一、界面技术架构（MVP 选型）

### 1.1 整体架构（本地 Web，3 层）

```
┌────────────────────────────── 你的 Mac（127.0.0.1） ──────────────────────────────┐
│                                                                                  │
│  Browser（打开 127.0.0.1:8000）                                                  │
│    └─ 前端：原生 HTML/CSS/JS（不做框架，MVP 最简）                                │
│                                                                                  │
│  FastAPI 壳服务（Python，:8000）── 我们自研的部分（薄壳）                          │
│    ├─ /api/* REST（采集/评分/编辑/发布/设置 接口）                                 │
│    ├─ 评分引擎（低粉高赞逻辑）                                                    │
│    ├─ 调用循环（间隔 1000ms、上限 50、翻页）                                      │
│    ├─ SQLite 存储（对标池/内容库/发布记录）                                       │
│    └─ Cookie 加密管理（macOS Keychain 封装）                                      │
│                                                                                  │
│  xiaohongshu-mcp 服务（Go，:18060）── 开源组件（拿来就用）                        │
│    └─ 登录/搜索/详情/发布（MCP HTTP 协议，13 个工具）                             │
│                                                                                  │
└──────────────────────────────────────────────────────────────────────────────────┘
                              │
                       小红书平台（账号老号）
```

### 1.2 为什么这样选

| 决策 | 选择 | 理由 |
|---|---|---|
| 后端壳 | **FastAPI（Python）** | 你技术栈限定 Python 在列；FastAPI 自带文档、轻量、开发快；比 Node/Go 写业务逻辑更快 |
| 前端 | **原生 HTML/CSS/JS** | MVP 界面简单（4 个 Tab），不引 Vue/React 省去构建链；后续要复杂化再升级 |
| 采集/发布引擎 | **xiaohongshu-mcp（Go 开源）** | 齿轮复用分析已验证：搜索/详情/发布全部现成；它自带 HTTP 端口，我们的壳直接调 |
| 数据库 | SQLite | 单机零配置 |
| 部署形态 | Docker 跑 xiaohongshu-mcp + uvicorn 跑壳 | **本机是 Intel Mac**：README 说预编译二进制暂不支持 darwin-amd64，**用 Docker 最稳**（Docker 已装 ✅） |

### 1.3 技术栈汇总
- 后端：Python + FastAPI + uvicorn
- 前端：HTML + CSS + 原生 JS（fetch 调 /api/*）
- 存储：SQLite（Python 内置 sqlite3）
- 外部：xiaohongshu-mcp（Docker 容器，:18060）
- 模型：MVP 人+豆包订阅；Phase2 API 配置项

## 二、需求模块细化（8 大模块）

| # | 模块 | 功能点 | 对应 UI | 状态 |
|---|---|---|---|---|
| M1 | 账号/Cookie | 登录二维码/状态检查/删除登录；Cookie 本地加密存储自动读取 | 设置页 | 复用开源+加密改造 |
| M2 | 采集 | 关键词/排序(综合/最新/收藏)/笔记类型(图文/视频/全部)/请求间隔(默认1000ms)/上限(默认50)/翻页/开始停止 | 采集页 | 复用+调用循环自研 |
| M3 | 结果管理 | 列表展示(标题/作者/摘要/互动)、筛选(标题/作者/ID)、全选、导出JSON | 结果页 | 自研(轻) |
| M4 | 评分推荐 | 低粉高赞优先、权重配置、标记可模仿 | 结果页(评分标) | 自研(核心) |
| M5 | 编辑创作 | 标题(≤50字)/正文(≤1000字)/话题标签(空格分隔)/图片(带入原图可删改调序追加)/可见范围/发布账号 | 编辑页 | 自研(UI) |
| M6 | 发布 | 发布前检查账号与上传通道/保存草稿/发布/定时发布/原创声明/绑定商品 | 编辑页 | 复用+串联 |
| M7 | 设置 | 模型后端配置(Phase2)/默认参数/账号列表管理 | 设置页 | 自研(轻) |
| M8 | 数据存储 | SQLite 表：accounts / notes(对标池) / drafts / publish_logs | 无(后台) | 自研(轻) |

## 三、UI 页面清单（4 页，对应视频 4 步 Tab）

| 页面 | 对应视频 | 主要元素 |
|---|---|---|
| **P1 采集页**（Tab: 搜索作品） | 视频 10s 帧 | 关键词输入、排序下拉、类型下拉、间隔/上限输入、开始/停止按钮、进度统计(已采页数/条数/耗时) |
| **P2 结果页**（Tab: 选择作品） | 视频 20s 帧 | 筛选框、结果卡片列表(标题/作者/摘要/互动/评分)、全选/导出JSON、已选计数 |
| **P3 编辑页**（Tab: 克隆创作） | 视频 24s/28s 帧 | 标题输入、正文文本域、话题标签、图片缩略图区(可删改调序追加)、可见范围、发布账号、原创声明、绑定商品、返回/保存草稿/发布按钮 |
| **P4 设置页** | 视频 Cookie 说明 | 账号登录状态、Cookie 管理、默认参数、模型后端(Phase2) |
