### 7层工作流（完整链路）
固定对标池 → 内容采集层 → 异常值识别层 → 内容分析层 → 二创生产层 → 发布执行层 → 回流复盘层

| 层 | 动作 |
|---|---|
| 固定对标池 | 先锁定已有成绩的对标博主作为稳定输入源 |
| 采集 | 每天采集对标主页内容进飞书采集库（标题/文案/互动数据/发布时间） |
| 异常值识别 | 同博主波动：平时2赞某篇5赞 = 异常候选，进标红池 |
| 分析 | 对标红内容做词云/关键词拆解，提取卖点词/人群词/痛点词 |
| 二创 | 基于异常值内容生成仿写标题、仿写文案、封面改图方案 |
| 发布 | 通过审核内容推发布管理，飞书插件生成二维码，手机扫码发布 |
| 复盘 | 发布结果回写表格，闭环 |

### 效率对比
- 传统：1篇1-2小时，产出不稳定
- AI工作流：5分钟/篇，新手10天发布100+篇，效率10倍

### ⭐仿写提示词模板（可直接抄）
核心参数：
- 保持25%-35%（一说30-40%）内容相似度
- 段落数量和组织顺序完全一致
- 保留40%核心内容（现象/数据），改写60%（描述/细节/表达）
- 结构：描述场景→分析原因→结合个人经历→介绍产品亮点
- 输出要求：口语化、emoji、结尾带#关键词、禁止直白引导词
- 替换：面对人群/用户痛点/产品卖点

### 关键方法论
- AI只是工具，真正提效前提是对业务/平台/用户足够了解
- 不要追求全自动化，AI+手动结合，先跑通单条闭环再批量
- 找对标标准：点赞>100、店铺出单>100
- 发布：二维码同步手机，扫码发布，多账号不出错
- 虚拟电商正反馈慢是因为效率低（1-2篇/天 vs 专业运营15篇/天），AI提效是关键

## 补充：布局搜索词章节（蓝海实拍电商场景）要点
- 核心理念：用户搜索的不是产品，而是具体的问题
- 三类关键词：产品词（桃木别针）/痛点词（频繁夜醒）/人群词（小月龄宝宝）
- 标题的搜索词收录率 > 正文
- 方法论：三类词爬取前200爆款标题 → AI提炼痛点场景 → 按场景×人群铺笔记（每月龄/每场景）
- 案例：桃木别针一年4万单，朋友同法3万单
- 意义：获客侧 SEO 打法，可与工具配合（大周推舟AI 也用了关键词覆盖）
