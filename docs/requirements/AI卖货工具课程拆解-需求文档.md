## 三、核心工作流（重构）

```
1. 输入行业/关键词（如"减肥"）
2. 粘贴小红书 Cookie（Windows 加密存本机）
3. 设置：结果上限50 / 排序综合 / 类型全部 / 间隔1000ms
4. 开始搜索 → 翻页采集小红书图文笔记（50条）
5. 系统评分 → 标记哪些笔记值得模仿
6. 筛选/勾选笔记 → 一键克隆
7. AI 生成新标题(≤50字) + 新正文(≤1000字) + 话题标签 + 带入图片
8. 选发布账号 → 自动检查账号和上传通道 → 发布
9. 内容引流 → 直播间获客
```
