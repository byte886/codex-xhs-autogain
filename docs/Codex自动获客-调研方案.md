# 「Codex 自动获客系统」赛道调研方案 v0.1（待对齐）

> 背景：视频已拆解出工具 = 「Codex 自动获客系统」：关键词 → 采集小红书笔记(50条) → 评分推荐 → 一键克隆(AI重写) → 发布到自有账号 → 引流直播间。

## 五、执行计划（分 4 步，可逐步确认）

### Step 1：生财站内普查（主渠道，先行）
1. `searchTopic`/`contentSearch` 搜关键词组：「自动获客」「小红书 采集」「小红书 克隆」「矩阵 发布」「一键克隆」「获客系统」
2. 按标签交叉：「Codex」+「小红书」+「AI产品开发」各翻页
3. 按 entityId 去重 → 相关性过滤 → 多维打标
4. 深读代表样本（高互动/精华，单批≤3，当轮落盘）
5. 落盘：`scys-普查清单.csv` + 重点帖摘要

### Step 2：航海手册 + AI 亦仁
1. 搜「超级 AI 大航海」及小红书/AI 航海手册 → 找「AI 工具开发/小红书运营」SOP
2. 向 AI 亦仁提问（判断题句式）：「想抄一个小红书 AI 自动获客工具，你判断这个方向值不值、坑在哪」
3. 落盘：航海 SOP 要点 + 亦仁观点

### Step 3：Google + 外部渠道（走代理）
1. 探代理端口 → curl 自测 → 导代理
2. Google 搜：`OpenAI Codex` 能力、`小红书 矩阵 工具`、`xhs 采集 开源 github`、`小红书 发布 API 风控`、`AI 获客 系统 卖课`
3. GitHub 搜小红书采集/发布开源项目（直连）
4. 交叉核验关键事实（≥2 独立来源）
5. 落盘：外部证据集（带 sourceUrl + 信源等级）

### Step 4：综合交付
1. 四组子问题逐条作答，每条附来源
2. 输出：《赛道调研报告》（赛道地图 + 可抄清单 + 技术可行性 + 复刻建议）
3. 明确「已查证 / 一方称 / 待核实」三态
