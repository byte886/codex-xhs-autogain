# 界面重构设计（对齐版 v1.0）

> 依据：视频 4 张关键帧（shot_10s/20s/24s/28s）+ 逐条对齐确认（2026-10-26）。
> 目标：把现有 4-Tab 简化版前端，重构为与视频真实界面一致的**单页一体式工作流**界面。
> 状态：范围已与用户逐条对齐 ✅，本文件为开发依据。

## 一、整体布局（单页一体式）

```
┌──────────────────────────────────────────────────────────┐
│  ⓘ 流程提示：待输入 → 搜索作品 → 筛选结果 → 选择作品        │ ← 纯提示，高亮当前阶段
├──────────────┬───────────────────────────────────────────┤
│  采集功能面板    │  右侧工作区（随流程阶段切换内容）           │
│  （固定左侧）   │  ┌ 待输入：空态等待输入提示               │
│  · 关键词搜索笔记│  │ 搜索作品：卡片网格实时填充 + 信息栏     │
│  · …7项置灰    │  │ 筛选结果：评分排序列表                │
│  · 参数区      │  │ 选择作品：勾选目标 + 悬浮按钮组        │
│  · Cookie 区   │  └ 发布编辑页（点一键克隆后整页切换）      │
└──────────────┴───────────────────────────────────────────┘
```

- **流程提示条**：四步文案 + 当前阶段高亮 + 状态（如"正在搜索作品（第2/4步）"），呼应视频右侧进程感
- **左侧面板**：始终可见（采集配置、Cookie、参数）
- **右侧工作区**：随阶段切换；发布编辑页为独立视图（底部有"返回作品列表"）

| 2 | 博主/对标账号采集 | 置灰 | 爬取博主整个主页作品（找对标） |
| 3 | 评论采集 | 置灰 | 批量采集笔记评论（一键采集客户的原料） |
| 4 | 指定链接采集 | 置灰 | 粘贴单条笔记链接采集 |
| 5 | 去水印下载 | 置灰 | 下载笔记原图/视频素材 |
| 6 | 热门/赛道采集 | 置灰 | 按热度/行业词采热门笔记 |
| 7 | 互动用户采集 | 置灰 | 采集点赞/收藏/评论用户名单（获客原料） |
| 8 | 定时/计划采集 | 置灰 | 设定时间自动跑采集任务 |

置灰项点击提示"即将上线"。**全部 7 项进功能待办**（docs/project/待办事项.md 同步）。

### 3.2 参数区

| 参数 | 默认 | 说明 |
|---|---|---|
| 关键词 | 空 | 搜索词输入框 |
| 结果上限 | 50 | 数字输入，可调（10/50/100） |
| 搜索排序 | 综合 | 下拉：综合 / 最新 / 最热（透传后端；容器接口若不支持最新/最热，先映射综合并标注待实测） |
| 笔记类型 | 全部 | 下拉：全部 / 图文 / 视频 |
| 全局请求间隔 | 1000ms | 数字输入（ms）；执行时以基准值 ± 随机抖动（拟人，不做固定机械间隔） |
| 按钮 | — | **开始搜索 / 停止** |

### 3.3 Cookie 区（4 件套）

| 控件 | 行为 |
|---|---|
| 显示 Cookie | 展开/收起；收起=星号脱敏，展开=明文可编辑 |
| Cookie 在哪里复制？ | 展开引导面板（V3，手动复制分步指引） |
| **导入 Cookie**（新增） | 一键从本机已登录小红书的 Chrome 导入：后端调 CDP 脚本 → 抓 cookie → 注入容器 → 校验登录态 → 界面显示登录账号。**不依赖 AI 在线**（纯代码执行）；需 Chrome 已开远程调试（一次性配置）+ 首次授权弹窗点"允许" |
| ☑ 加密保存到本机，下次自动读取 | 勾选后加密落盘（macOS：系统钥匙串/本地加密文件），下次启动自动注入 |

安全红线：cookie 为敏感凭证，明文仅在本机界面展示，不进日志、不进公开仓（检查 .gitignore）。

## 四、右侧工作区

### 4.1 待输入阶段
- 空态提示："请输入关键词，例如：翡翠"（呼应视频 10s 帧"比如说关键词输入一个减肥"）

### 4.2 搜索作品阶段（核心）
顶部**信息栏**：
| 元素 | 内容 |
|---|---|
| 搜索结果总数 | "共获取 N 条笔记" |
| 当前任务 | 显示关键词/任务名 |
| 状态 | 采集中 / 展示中 / 已停止 |
| 已采集数量 + 运行时间 | 实时更新（已采集 X 条 · MM:SS） |
| 筛选标题 | 输入框，按标题前端即时过滤卡片 |
| 批量操作 | 全选图文 / 下载图片 / 导出 JSON / 导出 CSV |

卡片网格：**图 + 标题 + 作者头像/昵称 + 互动数**（赞藏数）；采到一条出一条。

### 4.3 筛选结果阶段
- 评分排序列表（现有评分 TOP 逻辑），高分置顶，标"值得模仿"（呼应字幕"评分告诉我哪一条笔记应该去模仿他"）

### 4.4 选择作品阶段
- 卡片点击弹出菜单：**一键克隆 / 一键采集客户 / 打开原作品**
- 悬浮按钮组（对勾选卡片批量）：一键克隆（红）/ 一键采集客户
- 一键克隆 → 进入 V2 发布编辑页
- 一键采集客户 → 采互动用户名单（本轮只做名单采集+导出，触达合规后续议）

## 五、发布编辑页（V2）

| 字段 | 细节 |
|---|---|
| 标题 | 输入框 |
| 正文 | 最多 1000 字（对齐视频） |
| 话题标签 | 空格分隔多个（#号） |
| 图片 | 缩略图，可删改/调序/追加 |
| 可见范围 | 下拉（默认公开可见） |
| 发布账号 | 下拉切换（多账号矩阵） |
| 前置检查 | 点「发布至」前自动检查账号登录态 + 上传通道，失败拦截提示 |
| 原作品链接 | 附可复制链接（xsec_token 拼） |
| 底部按钮 | **返回作品列表 / 保存草稿 / 发布至** |

草稿存本地库，可再次打开编辑。
