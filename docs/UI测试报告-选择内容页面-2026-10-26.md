## 已知占位与未实现

- **采集客户（P4）**：当前为演示 toast，未做真实互动用户采集。设计上图文+视频均支持（按钮在两类卡片上都可用）。
- **下载图片包（P3）**：当前为演示 toast，未做真实 zip 下载。
- 批量条无「批量克隆/批量采客户」按钮：克隆走**卡片单条**（对齐视频方案），采集客户为单条占位。全选图文/清空选择服务于「勾选-导出/下载图片包」的批量场景。

## 生产/调试一致性

- 下载是**浏览器原生能力**：真实 Chrome 点「导出 JSON/CSV」文件直接落入 ~/Downloads，不依赖 CDP 注入、无需点击保存对话框。开发/调试/生产同一套行为。
- 测试侧注意：Playwright `connect_over_cdp` 的 context 默认**抑制下载**（测试夹具限制，非产品 bug），如需用 Playwright 断言下载必须显式 `Page.setDownloadBehavior {behavior:"allow"}`。
