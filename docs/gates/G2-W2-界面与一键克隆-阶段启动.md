## ① 目标对齐

**一句话**：把视频里那个工具的"操作界面"做出来——搜索关键词 → 看笔记列表（带评分排序）→ 一键克隆选中笔记 → 在编辑界面改标题/正文/标签/图片 → 点发布。跑通"采 → 选 → 改 → 发"完整闭环，**全部人工可操作**（MVP 不接 AI 生成）。

**可量化指标**：
1. 本地打开一个网页（127.0.0.1:8791 同款风格），有 4 个页面：采集面板 / 笔记列表 / 克隆编辑 / 发布记录
2. 输入关键词点"采集"，调用后端 → 真实写入 SQLite，列表实时刷新
3. 列表按评分排序，低粉爆款有标记，可点"一键克隆"进入编辑页
4. 编辑页：标题/正文/标签/图片 均可改（默认填充原笔记内容），可见范围可选手动发布
5. 点"发布"真实发到小红书（默认仅自己可见），发布记录有历史

## ② 范围确认

**做**：
- FastAPI 后端壳：把 MCP HTTP 封装成 REST API（搜索/详情/发布/登录状态），服务 :8791
- 原生前端（HTML/CSS/JS 单页应用，4 Tab）：搜索+采集 / 笔记列表+评分 / 克隆编辑 / 发布记录
- 一键克隆流程：列表选中 → 拉详情（desc/图片列表）→ 填充编辑页 → 本地下载图片到 docker/images
- 发布：调 MCP publish_content（可见范围参数可选）

**不做**（W3/W4 再做）：
- AI 生成标题/正文（D3：MVP=人+豆包订阅，人工编辑）
- 定时发布/批量发布
- 多账号/指纹浏览器
- 商品带货绑定（products 参数）
