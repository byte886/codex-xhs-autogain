## ① 目标对齐

**一句话**：搭好本地开发环境，跑通 xiaohongshu-mcp（Docker）+ 小红书老号登录，实现"按关键词采集 50 条笔记 → 字段落库 → 评分引擎跑出推荐排序"。

**可量化指标**：
1. 用"翡翠"关键词采集 ≥50 条小红书笔记
2. 每条含字段：标题 / 作者 / 内容摘要 / 图片URL / 笔记链接 / 互动数据（赞/藏/评）+ 发布时间 + 作者粉丝数
3. 数据落 SQLite 本地库，可查询可导出
4. 评分引擎对采集结果计算分数并排序（低粉爆款标记）

## ② 范围确认

**做**：
- Docker 部署 xiaohongshu-mcp（本机 Intel → Docker 最稳），起服务 :18060
- 小红书老号二维码登录（用户扫码），Cookie 本地保存
- 关键词采集 → 结构化落库 → 导出 JSON/CSV
- **评分数据流水线验证**：对候选笔记调 get_feed_detail + user_profile（拿时间/粉丝数）→ 跑评分公式 → 排序标记

**不做**（W2/W3 再做）：
- 编辑界面 UI（W2 开始）
- AI 生成标题/正文（MVP=人+豆包订阅，编辑界面人工处理）
- 发布模块正式串联（W3）；W1 仅做 1 条"仅自己可见"测试验证通道可用
- 多账号/指纹浏览器（W3 视需要）
